# VoicePrint

**A forensic research framework for speaker attribution in AI-generated voice blends.**

## TL;DR
VoicePrint is a research toolbox that answers one question: "Who is in there?" You feed it a synthetic voice blend (generated by a voice cloning service) and a set of reference voice samples. VoicePrint tells you which voices were used to create the blend, and how strongly each one contributed. This is not a speaker identification system. This is source attribution for synthetic speech.

## The Problem
Voice cloning is trivial now. You upload a few MP3s to a service, and you get a new, unique voice — a blend — that sounds like none of the individual sources, but is built from all of them. The catch: There is no way to tell which original voices were used. The AI doesn't tell you. The vendor doesn't tell you. The law doesn't know how to handle it. This is a problem for voice actors who want to know if their voice was used without consent, for lawyers who need technical evidence for copyright or personality rights cases, and for researchers who want to understand what these models actually learn. VoicePrint is my answer to that.

## What VoicePrint Does
VoicePrint takes a target audio file (the synthetic voice blend) and a set of reference MP3s (the suspected source voices) organized into two folders: Folder A with candidate source voices (suspected to be in the blend) and Folder B with control voices (confirmed not in the blend). It extracts speaker embeddings from all files using a state-of-the-art model (ECAPA-TDNN), computes cosine similarity between the blend and each reference, calculates a dynamic threshold based on the statistics of Folder B, and outputs a ranking with clear classification: contained, uncertain, or not contained.

## How It Works
VoicePrint uses ECAPA-TDNN (SpeechBrain) to turn every audio file into a vector — a mathematical fingerprint of the voice. It calculates the cosine similarity between the blend embedding and each reference embedding. The result is a number between 0 and 100% — higher means more similar. VoicePrint calculates the median and standard deviation of the similarity scores from Folder B (the control voices). The dynamic threshold is set to: threshold = median(Folder B) + 2 * stddev(Folder B). Classification: 🟢 ENTHALTEN (contained) when score > threshold (Folder A), 🟡 UNSICHER (uncertain) when score near threshold (Folder A or B), and 🔴 NICHT ENTHALTEN (not contained) when score < threshold (Folder B). When enabled, VoicePrint extracts additional voice attributes (pitch, timbre, energy, spectral centroid) to explain why a voice is classified as uncertain.

## The Reality Check
This is a research tool, not a forensic expert. Results are probabilistic and depend on audio quality, clone model, and recording conditions. Similarity scores are relative, not absolute. The threshold is dynamically calculated from your control voices. A score of 35% does not mean "35% of this voice is Speaker X." It means: "In the embedding space, this blend is closer to Speaker X than to the control voices." The ranking (A > B > C) is more reliable than the absolute numbers. Different voice cloning models warp embeddings differently. Results may vary. Always validate with multiple methods and consult a qualified expert for legal matters.

## Installation
Requirements: Windows 10/11 (or Linux/macOS with minor adjustments), Anaconda / Miniconda, NVIDIA GPU (recommended, but CPU works), Python 3.9+. Setup: Create conda environment with `conda create -n voiceprint python=3.9 -y` and `conda activate voiceprint`. Install PyTorch with CUDA using `pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121`. Install dependencies with `pip install speechbrain soundfile scipy numpy tkinter`.

## Usage
Launch the application with `python app.py`. Click Load Model — this downloads the ECAPA-TDNN model (~1.2 GB) on first run. Select your files: Select Clone Audio for the synthetic voice blend you want to analyze, Select Folder A for candidate source voices (suspected to be in the blend), and Select Folder B for control voices (confirmed not in the blend). Click Analyze — VoicePrint processes all files and displays the ranking. Optionally enable Attribute Analysis to get explanations for uncertain classifications. Optionally click Export Results to save the analysis as CSV or JSON.
